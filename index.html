Personal desktop utility · Private use

Writing, connected across devices.

Cxption Personal Drive Sync is a private desktop automation that moves a limited set of writing documents between one person's MacBook Air, their Google Drive and their MacBook Pro. This site documents what the utility does and how it handles access to Google user data. It does not offer public sign-up or host anyone's private documents.

What it does

  1. MacBook Air: on an hourly schedule, copies eligible writing files to a private folder in the owner's Google Drive.
  2. Google Drive: holds the shared writing files and a separate dated version-history folder.
  3. MacBook Pro: on an hourly schedule, downloads the eligible files from that Drive folder to the owner's local writing directory.

The workflow uses the open-source rclone command-line tool. It is intentionally one-way: Air → Drive → Pro. It is not a full Google Drive mirror, a hosted service, or a whole-computer backup.

Access and boundaries

Google's authorisation screen requests broad Google Drive file permissions because the rclone Drive integration uses the Drive API's full-access scope. The current automation is configured to operate only in the owner's selected 04 Creative/Shared Writing and 04 Creative/Shared Writing Versions folders. No scheduled file deletion is enabled. The local operator controls and can revoke access at any time.

Eligible document types include Markdown, text, RTF, PDF, DOCX, ODT and CSV, up to 50 MiB per file. The automated sync excludes unrelated media, application data, browser profiles and credentials.

Privacy and ownership

Private files are not hosted on this website or published to this repository. The workflow processes files locally and within the owner's own Google Drive. Access and refresh tokens remain in local, owner-restricted configuration files on each Mac. See the full policy for the types of data accessed, retention, sharing and revocation.
